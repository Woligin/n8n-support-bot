# n8n: бот первой линии поддержки на Gemini

Учебный проект: воркфлоу в n8n, который отвечает на вопросы клиентов службы доставки по заданным правилам.

## Что делает
- Принимает сообщение из чата (Chat Trigger).
- Передаёт его в Google Gemini через Basic LLM Chain вместе с системным промптом.
- Отвечает коротко и вежливо, на «вы».

## Правила бота (System Message)
- Возврат денег: сообщает срок 3 рабочих дня и просит номер заказа.
- Статус заказа: у бота нет доступа к данным заказов, поэтому он не обещает проверить сам, а просит номер и передаёт оператору.
- Вопросы не по теме (например, погода): вежливо возвращает разговор к доставке.
- Не здоровается повторно в каждом сообщении.

## Как проверялось
Три тестовых сценария в чате n8n:
1. «хочу вернуть деньги» → срок возврата + запрос номера заказа.
2. «где мой заказ» → запрос номера, передача оператору.
3. «какая у вас погода» → отказ по теме, возврат к вопросам доставки.

## Стек
n8n (self-hosted, `npx n8n`), Google Gemini API, Basic LLM Chain.

## Запуск
1. `npx n8n`, затем открыть localhost:5678.
2. Импортировать `support-bot.json` (Ctrl+V на холст).
3. Создать credentials Google Gemini (PaLM) API со своим ключом.
4. Open chat и написать вопрос.

## Ограничения
Бот не хранит историю диалога и не подключён к реальной базе заказов. Следующие шаги: память диалога, Telegram-вход, запись вопросов в Google Sheets.
